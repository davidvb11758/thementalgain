# MY CLIENTS PAGE – Text Content

> **Notes for the reader of this doc**

> - Page: `site/my-clients.html`. Run `npm run bake:site` after editing this file.
> - **Text blocks:** `**ID:** my-clients-…` → the text of the element with that `id` in `my-clients.html`. Each is a single heading or paragraph. A line ending in `\` starts a new line inside the paragraph.
> - **Client lists:** `my-clients-individual-groups` and `my-clients-team-groups` are regenerated by `site/scripts/render_my_clients_from_md.py` between the `<!-- …:start -->` / `<!-- …:end -->` markers in the HTML. Each `###` heading starts a group (a club or category) and each `*` bullet under it is one chip. Add `{wide}` at the end of a heading for a group with long entries (a wider chip grid). To add, remove or reorder groups or chips, edit them here.
> - **Not in this file:** the testimonial images and the school logos (including their alt text) live in `my-clients.html`.
